# Mediavault Agent Instructions

Read and follow `AGENTS.md`, the canonical repository guidance for every coding agent.

Do not duplicate architecture, runtime, command, security, or verification rules here. In particular, the former Bun-only, shared-password, config-owned-user, JSON-storage, and mandatory commands/queries folder examples are obsolete.

Use the supported Node.js LTS and pnpm versions declared by the repository. Preserve explicit server/browser and authorization boundaries. Research notes, execution tracking, decision logs, and temporary QA evidence must remain outside Git. Ask the maintainer before consequential architecture or policy decisions, and do not create commits without explicit authorization.
